# 用語集

| 用語 | 説明 |
| --- | --- |
| Kconfig | ビルド時の機能選択と依存関係を表現する設定言語・仕組み。結果は`.config`や`autoconf.h`になる。 |
| Devicetree | ハードウェア構成をノードとプロパティで表現する記述。処理後にCマクロなどを生成する。 |
| binding | Devicetreeノードの`compatible`ごとのプロパティ契約を定義するYAMLファイル。 |
| device | Zephyrのドライバ実体を表す`struct device`。構成、状態、API表を結び付ける。 |
| SYS_INIT | `main()`前後の初期化関数を、レベルと優先度で登録するマクロ。 |
| west | Zephyrのワークスペースとビルドを扱うメタツール。 |
| workspace | `.west/`を基点に、manifestが指定するZephyr、module、toolを配置するディレクトリ。 |
| manifest | westが複数リポジトリのURL、revision、配置先を解決するYAML記述。Zephyrでは`west.yml`が入口になる。 |
| module | Zephyr本体とは別リポジトリで提供され、manifestで取り込まれるHAL、ライブラリ、ブートローダなどの外部プロジェクト。 |
| toolchain | C/C++／アセンブリをターゲット用オブジェクトへ変換するコンパイラ、アセンブラ、リンカなどの組。 |
| Zephyr SDK | 対応アーキテクチャ用のGNU／LLVM toolchainと、QEMU、OpenOCDなどのhost toolを含むSDK。 |
| CMake cache | 構成時に検出・決定した変数を記録する`CMakeCache.txt`。入力を変えたときはpristine buildが必要になる場合がある。 |
| ELF | 実行可能・リンク可能形式（Executable and Linkable Format）。`zephyr.elf`はデバッグ情報を含むリンク結果。 |
| map file | リンカが出力する、シンボルとセクションの配置を追うためのファイル。 |
| ISR | 割り込みサービスルーチン（Interrupt Service Routine）。通常のスレッドとは異なる割り込みコンテキストで実行される。 |
| thread | カーネルがスケジュールする実行単位。entry function、stack、`struct k_thread`、priorityを持つ。 |
| work queue | `k_work`を登録し、専用のthreadでhandlerを実行する遅延処理機構。ISRで重い処理を行わないための受け渡し先の一つ。 |
| semaphore | 利用可能な回数やイベント到着を表し、threadの待機・起床に使うkernel object。 |
| mutex | 一つのthreadだけが共有資源を所有して操作するためのkernel object。 |
| stack | 関数呼出の文脈やlocal variableを保持する領域。Zephyrではthreadごとにstackを持つ。 |
| system heap | `CONFIG_HEAP_MEM_POOL_SIZE`でsizeを決める、動的allocation用の共通pool。allocation失敗を処理する必要がある。 |
| ABI | アプリケーション・バイナリ・インターフェース（Application Binary Interface）。関数呼出規約、データ配置、オブジェクト形式などのバイナリ互換契約。 |
