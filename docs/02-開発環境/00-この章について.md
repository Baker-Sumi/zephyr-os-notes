# 導入と開発環境

## 対象範囲

Zephyr v4.4.2を公式手順で導入した後に、どのディレクトリ、設定、ツール、生成物を観察すれば内部構造を追えるかを扱います。OSごとの依存パッケージの問題解決、特定デバッグプローブの設定、製品用の配布手順は扱いません。
