# 開発・解析コマンド

## 対象範囲

west本体とZephyr拡張commandを、実行目的、入力、生成物・副作用、ハードウェア依存性で整理します。各board runnerの詳細やCI設定は扱いません。

## 全体像

`west`本体はworkspace、manifest、設定を扱うメタツールです。Zephyrは[`scripts/west-commands.yml`](https://github.com/zephyrproject-rtos/zephyr/blob/v4.4.2/scripts/west-commands.yml)でPython実装を登録し、build、flash、debug、test、SDK操作などを拡張します。

| コマンド | 実装または主な入力 | 出力・副作用 | 依存条件 |
| --- | --- | --- | --- |
| `west init`、`west update` | manifest、Git | `.west/`とmanifest指定project | Git、network、workspace |
| `west manifest --resolve` | manifestとimport | 解決済みmanifestを標準出力へ表示 | workspace |
| `west boards`、`west shields` | board/shield metadata | 候補一覧 | Zephyr source |
| `west build` | app、board、CMake、Kconfig、DTS | build directory、ELF、image | host tools、toolchain |
| `west flash` | 既存build、board runner | board上のflashを書き換える | 接続済みboard、runner、権限 |
| `west debug`、`debugserver`、`attach` | 既存build、runner | debuggerまたはdebug server | probeまたはsimulator |
| `west rtt`、`reset` | runner | RTT接続またはtarget reset | 対応runner |
| `west twister` | tests、platform metadata | test build・report | toolchain、選択時はemulator/hardware |
| `west sdk` | SDK command | SDKのinstall・管理 | networkまたはSDK bundle |
| `west zephyr-export` | Zephyr CMake package | CMake package registry | CMake |

## 処理の流れ

1. `west -h`は、west本体とmanifestが登録したextensionを併せて表示します。
2. 上流Zephyrでは`west.yml`の`self.west-commands`が`scripts/west-commands.yml`を指します。
3. `scripts/west-commands.yml`がcommand名と`script/west_commands/*.py`のclassを対応付けます。
4. `west build`はCMake/Ninjaを起動して出力だけを更新します。一方、`flash`、`reset`、debug commandはtargetの状態を変える可能性があります。

## 設定との対応

- `west config build.board <board>`はwestの既定boardを保存します。Kconfigではないため、`prj.conf`には書きません。
- `west build -- -DDTC_OVERLAY_FILE=...`や`-DEXTRA_CONF_FILE=...`はCMake configureへの入力です。既存build directoryではCMake再実行またはpristine buildが必要です。
- `west build -p always`はbuild directoryをpristineにして構成し直します。sourceを削除せず、古いconfigure出力を破棄するために使います。

> **注意: 実機操作を解析コマンドと同一視しない**
>
> `west build`、`manifest --resolve`、`boards`はhost上の観察・生成です。`flash`、`reset`、`debug`は接続先の状態に影響します。run前にrunner、board、接続先を確認してください。

## 確認方法

```sh
cd <workspace>/zephyr
west -h
west build -h
west boards | head
grep -nE 'name: (build|flash|debug|twister|sdk)$' scripts/west-commands.yml
west manifest --resolve > /tmp/zephyr-v4.4.2-manifest.yml
```

`/tmp/zephyr-v4.4.2-manifest.yml`は一時確認用です。製品の依存を固定する場合は、出力をコピーするのではなく、管理下のdownstream manifestを作成します。
