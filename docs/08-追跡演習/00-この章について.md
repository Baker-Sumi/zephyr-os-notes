# 追跡演習

短いAPI呼び出しを、設定・生成物・デバイス・ドライバ実装まで追います。

- [導入環境からBlinkyを追う](01-導入環境からBlinkyを追う.md)は、west workspaceからGPIOドライバまでの全体経路を扱います。
- [GPIO呼び出しを追う](03-GPIO呼び出しを追う.md)と[UARTとコンソールを追う](04-UARTとコンソールを追う.md)は、個別APIをより短い経路で追います。
- [Blinkyの設定差分を観察する](02-Blinkyの設定差分を観察する.md)は、nRF52840 DKで入力を変え、生成物の差分を根拠に設定の反映先を確認します。
- [実行コンテキストを観察する](05-実行コンテキストを観察する.md)は、thread・ISR・work queueの間で処理を渡す最小経路を追います。
- [ボード差分を観察する](06-ボード差分を観察する.md)は、nRF52840 DKとESP32-C6搭載基板で、board入力が生成物へ与える差分を比較します。
